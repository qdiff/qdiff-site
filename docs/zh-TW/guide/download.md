# 取得與安裝

qDiff 是一個輕巧的 Mac 原生 App。裝好之後，拖兩下就能開始第一次比較。

<DownloadButtons />

## 很快裝好

1. 打開 Mac App Store 頁面，點「取得」，再點「安裝」。
2. 從「應用程式」或啟動台打開 qDiff。
3. 把兩個檔案或兩個資料夾拖進視窗 —— 就這樣，沒有別的設定。

::: tip 關於資料夾授權
第一次比較資料夾時，macOS 可能會詢問是否允許 qDiff 查看這個資料夾，選「允許」
即可。主動權始終在你手裡：只有你選過的資料夾會被讀取，之後也能在設定裡改。
:::

## 系統需求 {#system-requirements}

| | |
| --- | --- |
| 系統 | macOS 12 或更新 |
| 機型 | Apple 晶片與 Intel 均可 |
| 帳號 | 不需要 |
| 網路 | 比較檔案不需要連網 |
| 介面語言 | 英文、簡體中文、繁體中文、日文、德文、西班牙文、法文 |
| 外觀 | 淺色與深色 |

## 免費使用，另有一次性的選購項目

所有比較、查看和匯出功能，不付費也能用。免費版只是在標籤列上多一個
「未授權」小標記。一次性購買會去掉這個標記，並包含以後新增的進階功能 ——
沒有訂閱、沒有廣告、不需要帳號。購買記錄與你的 Apple ID 綁定，隨時可以在
設定裡恢復。
