# 常見問題

### qDiff 免費嗎？

免費。所有比較、查看和匯出功能，不付費也能用。免費版只在標籤列上多一個
「未授權」小標記。一次性購買會去掉它，並包含以後新增的進階功能。沒有訂閱，
也沒有廣告。

### 購買之後會解鎖新功能嗎？

不會 —— 功能本來就全部可用。購買只是去掉那個小標記。以後如果增加進階能力，
也會算在同一次購買裡，不會再賣第二個商品。

### 換電腦後怎麼恢復購買？

打開「設定 → 進階功能」，點「恢復購買」。購買記錄與 Apple ID 綁定，在你的
其他 Mac 上同樣有效。

### 支援哪些 Mac？

macOS 12 或更新版本，Apple 晶片與 Intel 機型都可以，詳見
[系統需求](./download.md#system-requirements)。

### 需要帳號或連網嗎？

不需要。qDiff 離線可用，不用登入，也沒有背景服務。它只打開你選擇的檔案和
資料夾。

### 能比較整個資料夾和壓縮檔嗎？

能。資料夾以樹狀展開，可按狀態篩選、直接複製和同步；.zip / .tar 不用解壓，
也能當資料夾來比。

### 圖片和不是文字的檔案呢？

圖片可以並排看，也可以疊加看差異；不是純文字的檔案，還能細到最小的差別。
見[更多比較方式](./more.md)。

### 你們會上傳或分析我的檔案嗎？

不會。不收集、不追蹤、不上傳，完整說明見[隱私政策](../privacy/)。

### 支援哪些語言？

App 與本站提供七種語言：英文、簡體中文、繁體中文、日文、德文、西班牙文、法文，
並支援淺色與深色外觀。

### 用的時候遇到問題怎麼辦？

[聯絡我們](./support.md)，附上 macOS 版本和一句症狀描述就好；有截圖會更快。
