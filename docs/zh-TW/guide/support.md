# 聯絡我們

看不懂的地方、打不開的檔案、對下一版的想法 —— 每一封郵件我們都會看。

**信箱：** [qdiff@w3cub.com](mailto:qdiff@w3cub.com)

中文或英文都可以。

## 怎樣描述，回覆更快

- 你的 macOS 版本和機型。
- qDiff 版本（在 App 選單裡打開「關於 qDiff」）。
- 當時在比較什麼，原本期望看到什麼。
- 如果問題看得見，附一張截圖。

不方便分享的檔案就不用發，一段描述或裁過的截圖通常已經夠了。

## 寫信之前

[常見問題](./faq.md)收了最常被問到的幾件事，[認識 qDiff](./introduction.md)

## 關於購買與退款

購買和退款由 Mac App Store 與你的 Apple ID 處理。帳單問題找 Apple 支援最快；
在 qDiff 裡恢復購買的方法見[常見問題](./faq.md)。
