# プライバシーポリシー

_最終更新日: 2026年11月6日_

**要点をお伝えすると、qDiff は個人データを収集しません。** ローカルで動作する
ツールです。ファイルはお使いの Mac 内に留まります。

## qDiff が読み取るもの

qDiff は、アプリ内で選んだファイルとフォルダだけを開き、比較を表示するために
お使いのデバイス上で処理します。フォルダへのアクセスを許可した場合、その
権限は利便性のために保持されますが、「設定」からいつでも取り消せます。
私たちにアップロードされるものは何もありません。

## 行わないこと

- 氏名、メールアドレス、利用統計は収集しません。
- アプリやウェブサイトを横断して追跡しません。
- アカウントやサインインを要求しません。
- 広告の表示、解析やサードパーティによる追跡の組み込みは行いません。
- ファイルをサーバーへ同期・バックアップしません。

## ネットワークアクセス

qDiff はオフラインで動作します。唯一任意で行われるネットワーク通信は、
アプリ内の「その他のアプリ」ページで公開アプリ一覧を読み込むときだけです。
この通信には、あなた、ファイル、デバイスに関する情報は一切含まれず、
利用データが送信されることもありません。

## 購入

任意の一度きりの購入は、Mac App Store とお使いの Apple ID によって完全に
処理されます。私たちが支払い情報を目にすることはありません。購入はアプリ内の
「設定」から復元できます。

## このウェブサイトについて

このサイトは静的なページの集まりです。ログイン、解析、広告用 Cookie は
ありません。ページを開くだけで、何かをご提供いただく必要は生じません。

## 子どもについて

qDiff は子どもを対象としておらず、故意に情報を収集することはありません。

## 変更について

本ポリシーを変更する場合は、このページと上記の日付を更新します。アプリが
読み取る内容に影響する変更は、アプリ本体でもお知らせします。
