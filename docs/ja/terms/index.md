# 利用規約

_最終更新日: 2026年11月6日_

qDiff をご利用いただき、ありがとうございます。本規約はアプリとこのウェブサイトに
適用されます。

## アプリのご利用について

qDiff は、ご自身のファイルを比較・整理するためのものです。ご家庭でも職場でも
ご利用いただけます。開くファイルを選ぶ責任、および大切なデータのバックアップを
保つ責任は、お客様にあります。

アプリは「現状のまま」提供されます。信頼性のために努めていますが、中断や
エラーが一切ないことをお約束することはできず、データの消失について責任を
負いかねます。ファイルの同期や削除の前には、必ずバックアップをお取りください。

## 無料版と購入

すべての比較機能は無料です。無料版ではタブバーに小さなマークが表示されます。
一度きりの非消耗型の購入でこのマークが消え、今後追加されるプレミアム機能も
含まれます。サブスクリプションはありません。

購入、返金、復元は Apple の規約とお使いの Apple ID のもと、Mac App Store で
処理されます。私たちがお支払い情報を受け取ることはありません。

## お客様のコンテンツ

私たちはお客様のファイルに対していかなる権利も主張せず、ファイルを受け取る
こともありません。詳しくは[プライバシーポリシー](../privacy/)をご覧ください。

## このウェブサイトについて

このサイトのコンテンツは情報提供のみを目的としています。qDiff の改善に伴い、
製品の説明は更新される場合があります。

## 変更について

本規約を更新する場合があり、その際は上記の日付が変わります。更新後も
qDiff のご利用を続けられた場合、改訂後の規約に同意されたものとみなされます。
