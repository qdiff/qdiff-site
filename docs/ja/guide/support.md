# お問い合わせ

分かりにくい点、開かないファイル、次期バージョンへのご要望 —— いただいた
メッセージはすべて拝見しています。

**メール:** [qdiff@w3cub.com](mailto:qdiff@w3cub.com)

英語または日本語でお送りください。

## 解決に役立つ情報

- お使いの macOS のバージョンと、Mac の機種。
- qDiff のバージョン（アプリメニューの**qDiff について**から確認できます）。
- 何を比較していて、何が表示されると想定していたか。
- 画面で確認できる問題であれば、スクリーンショット。

共有したくないファイルは添付しないでください。説明や、必要な部分だけを
切り取ったスクリーンショットでたいてい十分です。

## ご連絡の前に

[FAQ](./faq.md)にはよくあるご質問への回答をまとめており、
[ご紹介](./introduction.md)では最初の比較を順を追って説明しています。
プライバシーに関するご質問は、qDiff が何を読み取り、何を読み取らないかを
正確に記した[プライバシーポリシー](../privacy/)をご覧ください。

## 購入と返金について

購入と返金は、Mac App Store とお使いの Apple ID によって処理されます。
課金に関するお問い合わせは Apple サポートが最短です。qDiff 内で購入を
復元する方法は[FAQ](./faq.md)をご覧ください。
