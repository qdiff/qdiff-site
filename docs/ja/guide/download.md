# 入手とインストール

qDiff は小さく軽い Mac ネイティブアプリです。インストールすれば、最初の比較は
ドラッグ 2 回で始められます。

<DownloadButtons />

## あっという間にインストール

1. Mac App Store のページを開き、**入手**をクリックしてから**インストール**を
   クリックします。
2. 「アプリケーション」フォルダまたは Launchpad から qDiff を起動します。
3. 2 つのファイル、または 2 つのフォルダをウィンドウにドラッグします。
   設定はこれだけです。

::: tip フォルダへのアクセスを許可する
初めてフォルダを比較するとき、macOS から qDiff にそのフォルダの中を見てよいか
尋ねられる場合があります。**許可**を選んでください。管理権限は常にあなたに
あり、読み取られるのは選んだフォルダだけです。この設定は後から「設定」で
変更できます。
:::

## システム要件 {#system-requirements}

| | |
| --- | --- |
| システム | macOS 12 以降 |
| Mac | Apple シリコンおよび Intel |
| アカウント | 不要 |
| インターネット | 比較には不要 |
| 言語 | 英語、簡体字中国語、繁体字中国語、日本語、ドイツ語、スペイン語、フランス語 |
| 外観 | ライトとダーク |

## 無料、任意の一度きりの購入あり

すべての比較・表示・書き出し機能は、支払いなしでご利用いただけます。無料版では
タブバーに「未ライセンス」のマークが表示されるだけです。一度きりの購入でこの
マークが消え、今後追加されるプレミアム機能も含まれます。サブスクリプション、
広告、アカウントはありません。購入は Apple ID に紐づき、「設定」からいつでも
復元できます。
