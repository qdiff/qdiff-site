# よくあるご質問

### qDiff は無料ですか？

はい。すべての比較・表示・書き出し機能を、支払いなしでご利用いただけます。
無料版ではタブバーに小さな「未ライセンス」のマークが表示されるだけです。
一度きりの購入でこのマークが消え、今後追加されるプレミアム機能も含まれます。
サブスクリプションも広告もありません。

### 購入すると何か機能が増えますか？

いいえ。すべての機能は最初から利用できます。購入で変わるのは、あのマークが
消えることだけです。今後プレミアム機能を追加する場合も、新しい商品ではなく
同じ一度きりの購入に含まれます。

### 購入を復元するには？

**設定 → プレミアム**を開き、**購入を復元**を選びます。購入は Apple ID に
紐づいているため、お使いの他の Mac でも有効です。

### 対応している Mac は？

macOS 12 以降で、Apple シリコン搭載 Mac と Intel Mac に対応しています。
[システム要件](./download.md#system-requirements)もご覧ください。

### アカウントやインターネット接続は必要ですか？

いいえ。qDiff はオフラインで動作し、サインインも不要で、バックグラウンド
サービスもありません。選んだファイルとフォルダだけを開きます。

### フォルダ全体やアーカイブも比較できますか？

はい。フォルダは状態フィルタやコピー／同期の操作を備えたツリーで開きます。
.zip や .tar アーカイブも、解凍せずにフォルダのように比較できます。

### 画像やテキスト以外のファイルはどうですか？

画像は並べて表示することも、重ねて表示することもできます。プレーンテキスト
ではないファイルも、ごく細かな違いまで比較できます。
[その他の比較方法](./more.md)をご覧ください。

### ファイルをアップロードしたり分析したりしますか？

いいえ。収集・追跡・同期は一切行いません。詳しい説明は
[プライバシーポリシー](../privacy/)にあります。

### 日本語など他言語のインターフェースはありますか？

はい。英語、簡体字中国語、繁体字中国語、日本語、ドイツ語、スペイン語、フランス語の 7 言語に対応し、ライトとダークの外観も選べます。

### うまく動きません。どうすればよいですか？

macOS のバージョンと、起きたことの簡単な説明を添えて
[お問い合わせ](./support.md)からご連絡ください。スクリーンショットがあると
とても助かります。
