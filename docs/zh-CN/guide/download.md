# 获取与安装

qDiff 是一个轻巧的 Mac 原生应用。装好之后，拖两下就能开始第一次比较。

<DownloadButtons />

## 很快装好

1. 打开 Mac App Store 页面，点「获取」，再点「安装」。
2. 从「应用程序」或启动台打开 qDiff。
3. 把两个文件或两个文件夹拖进窗口 —— 就这样，没有别的设置。

::: tip 关于文件夹授权
第一次比较文件夹时，macOS 可能会询问是否允许 qDiff 查看这个文件夹，选「允许」
即可。主动权始终在你手里：只有你选过的文件夹会被读取，之后也能在设置里改。
:::

## 系统要求 {#system-requirements}

| | |
| --- | --- |
| 系统 | macOS 12 或更新 |
| 机型 | Apple 芯片与 Intel 均可 |
| 账号 | 不需要 |
| 网络 | 比较文件不需要联网 |
| 界面语言 | 英文、简体中文、繁体中文、日文、德文、西班牙文、法文 |
| 外观 | 浅色与深色 |

## 免费使用，另有一次性的可选购买

所有比较、查看和导出功能，不付费也能用。免费版只是在标签条上多一个
「未授权」小标记。一次性购买会去掉这个标记，并包含以后新增的高级功能 ——
没有订阅、没有广告、不需要账号。购买记录与你的 Apple ID 绑定，随时可以在
设置里恢复。
