# 常见问题

### qDiff 免费吗？

免费。所有比较、查看和导出功能，不付费也能用。免费版只在标签条上多一个
「未授权」小标记。一次性购买会去掉它，并包含以后新增的高级功能。没有订阅，
也没有广告。

### 购买之后会解锁新功能吗？

不会 —— 功能本来就全部可用。购买只是去掉那个小标记。以后如果增加高级能力，
也会算在同一次购买里，不会再卖第二个商品。

### 换电脑后怎么恢复购买？

打开「设置 → 高级功能」，点「恢复购买」。购买记录与 Apple ID 绑定，在你的
其他 Mac 上同样有效。

### 支持哪些 Mac？

macOS 12 或更新版本，Apple 芯片与 Intel 机型都可以，详见
[系统要求](./download.md#system-requirements)。

### 需要账号或联网吗？

不需要。qDiff 离线可用，不用登录，也没有后台服务。它只打开你选择的文件和
文件夹。

### 能比较整个文件夹和压缩包吗？

能。文件夹以树形展开，可按状态筛选、直接复制和同步；.zip / .tar 不用解压，
也能当文件夹来比。

### 图片和不是文本的文件呢？

图片可以并排看，也可以叠加看差异；不是纯文本的文件，还能细到最小的差别。
见[更多比较方式](./more.md)。

### 你们会上传或分析我的文件吗？

不会。不收集、不追踪、不上传，完整说明见[隐私政策](../privacy/)。

### 界面有中文吗？

有简体中文、繁体中文、英文等多种语言，并支持浅色与深色外观。

### 用的时候遇到问题怎么办？

[联系我们](./support.md)，附上 macOS 版本和一句症状描述就好；有截图会更快。
