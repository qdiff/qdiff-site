# 认识 qDiff

qDiff 只回答一个问题：**到底改了哪儿？** 把两个版本并排放好，不同的地方
会用颜色标出来，不用再靠眼睛一行一行对。

<img src="/screenshots/files.svg" alt="两份文件并排比较" class="guide-shot" />

## 大家最常拿来做的三件事

- **比两份文件** —— 初稿与改后稿、改前改后的配置、两次导出的内容。一行里
  改动的那几个字也会单独标出来。
- **比两个文件夹** —— 工作目录和它的备份。多了什么、改了什么、少了什么，
  一眼就能挑出来，还能顺手让两边一致。
- **看一个项目文件夹** —— 改动过的文件排成一列，逐个看差异、提交，不用
  在几个窗口之间来回切。

图片、压缩包，以及不是纯文本的文件也能比，[看看还有哪些用法](./more.md)。

## 三步开始

1. 打开 qDiff，把两个文件或文件夹拖到窗口里；也可以从「文件」菜单选择。
2. 看带颜色的行。点侧边的小地图，或者用「上一处 / 下一处」按钮逐个查看。
3. 需要调整就直接改、复制、同步；要给别人看，就把这次比较存成一张图。

::: tip 不用先设置
不用注册账号，第一次比较之前也没有什么要配置的，离线就能用。
:::

## 免费，也安心

所有比较功能都免费。免费版只在标签条上多一个小标记，一次性购买即可去掉。
qDiff 只读取你选择的文件，不会把内容发出去，详见[隐私政策](../privacy/)。
