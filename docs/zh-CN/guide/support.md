# 联系我们

看不懂的地方、打不开的文件、对下一版的想法 —— 每一封邮件我们都会看。

**邮箱：** [qdiff@w3cub.com](mailto:qdiff@w3cub.com)

中文或英文都可以，日文、德文、西班牙文、法文也欢迎。

## 怎样描述，回复更快

- 你的 macOS 版本和机型。
- qDiff 版本（在应用菜单里打开「关于 qDiff」）。
- 当时在比较什么，原本期望看到什么。
- 如果问题看得见，附一张截图。

不方便分享的文件就不用发，一段描述或裁过的截图通常已经够了。

在 qDiff 里恢复购买的方法见[常见问题](./faq.md)。
