# 提交前看一遍

每次提交前问一句「我到底改了什么」，都很值得。用 qDiff 打开项目文件夹，
答案已经摆好了。

<img src="/screenshots/projects.svg" alt="改动文件列表与右侧彩色差异" class="guide-shot" />

## 打开项目文件夹

从「文件 → 打开」选一个 Git 项目文件夹，或者直接拖进窗口。qDiff 会把你动过的
文件收成一列。

## 先看列表，再看差异

每个文件都标着它的状态：新增、修改、删除。点开一个，右边就显示里面具体改了
什么，颜色和按词高亮跟普通文件比较完全一样。

一个一个看过去就好，列表会记住你看到哪儿，改动再多也不容易漏。

## 在同一个窗口里收尾

确认没问题，直接在这里提交。更新、推送、还原、解决冲突也都能在比较界面里完成，
不用再开别的工具，也不需要账号。

::: tip 不是项目文件夹？
普通文件夹照样能当文件夹来比，[比较文件夹](./folders.md)在任何目录都可用。
:::
