# Descargar e instalar

qDiff es una aplicación nativa de Mac, ligera y pequeña. Instálela y su primera
comparación estará a solo dos arrastres de distancia.

<DownloadButtons />

## Instalación en un momento

1. Abra la página de qDiff en el Mac App Store y pulse **Obtener** y luego
   **Instalar**.
2. Inicie qDiff desde la carpeta Aplicaciones o desde Launchpad.
3. Arrastre dos archivos —o dos carpetas— a la ventana. Eso es todo.

::: tip Cómo conceder acceso a una carpeta
La primera vez que compare una carpeta, macOS puede preguntarle si permite que
qDiff examine su contenido. Elija **Permitir**. Usted mantiene el control: solo
se leen las carpetas que elija y puede cambiar esto más adelante en Ajustes.
:::

## Requisitos del sistema {#system-requirements}

| | |
| --- | --- |
| Sistema | macOS 12 o posterior |
| Mac | Chip de Apple e Intel |
| Cuenta | No se requiere |
| Internet | No se necesita para comparar |
| Idiomas | inglés, chino simplificado, chino tradicional, japonés, alemán, español y francés |
| Apariencia | Clara y oscura |

## Gratuito, con una compra única opcional

Todas las comparaciones, vistas y exportaciones funcionan sin pagar. La versión
gratuita simplemente muestra una marca de «Sin licencia» en la barra de
pestañas. Una sola compra elimina esa marca e incluye futuros extras premium:
sin suscripción, sin anuncios y sin cuenta. Las compras están vinculadas a su
Apple ID y puede restaurarlas en cualquier momento desde Ajustes.
