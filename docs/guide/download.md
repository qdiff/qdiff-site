# Get & install

qDiff is a small, native Mac app. Install it and your first comparison is two
drags away.

<DownloadButtons />

## Install in a moment

1. Open the Mac App Store page and click **Get**, then **Install**.
2. Launch qDiff from the Applications folder or Launchpad.
3. Drag two files — or two folders — onto the window. That is the whole setup.

::: tip Granting access to a folder
The first time you compare a folder, macOS may ask whether qDiff may look
inside it. Choose **Allow**. You stay in control: only folders you pick are
read, and you can change this later in Settings.
:::

## System requirements {#system-requirements}

| | |
| --- | --- |
| System | macOS 12 or later |
| Mac | Apple silicon and Intel |
| Account | Not required |
| Internet | Not required for comparing |
| Languages | English, Simplified Chinese, Traditional Chinese and more |
| Appearance | Light and dark |
