# Herunterladen & installieren

qDiff ist eine kleine, native Mac-App. Installieren Sie sie, und der erste
Vergleich ist nur zwei Ziehbewegungen entfernt.

<DownloadButtons />

## In einem Moment installiert

1. Öffnen Sie die Mac-App-Store-Seite und klicken Sie auf **Holen**, dann auf
   **Installieren**.
2. Starten Sie qDiff aus dem Ordner „Programme“ oder über das Launchpad.
3. Ziehen Sie zwei Dateien — oder zwei Ordner — ins Fenster. Das war die ganze
   Einrichtung.

::: tip Zugriff auf einen Ordner erlauben
Wenn Sie zum ersten Mal einen Ordner vergleichen, fragt macOS möglicherweise,
ob qDiff hineinsehen darf. Wählen Sie **Erlauben**. Sie behalten die Kontrolle:
Es werden nur Ordner gelesen, die Sie auswählen, und Sie können dies später in
den Einstellungen ändern.
:::

## Systemvoraussetzungen {#system-requirements}

| | |
| --- | --- |
| System | macOS 12 oder neuer |
| Mac | Apple-Chip und Intel |
| Konto | Nicht erforderlich |
| Internet | Für den Vergleich nicht erforderlich |
| Sprachen | Englisch, vereinfachtes Chinesisch, traditionelles Chinesisch, Japanisch, Deutsch, Spanisch und Französisch |
| Darstellung | Hell und dunkel |

## Kostenlos, mit optionalem einmaligem Kauf

Jeder Vergleich, jede Ansicht und jeder Export funktioniert ohne Bezahlung. Die
kostenlose Version zeigt lediglich einen „Nicht lizenziert“-Hinweis in der
Tableiste. Ein einmaliger Kauf entfernt diesen Hinweis und schließt künftige
Premium-Extras ein — kein Abo, keine Werbung, kein Konto. Käufe sind an Ihre
Apple ID gebunden und können jederzeit in den Einstellungen wiederhergestellt
werden.
