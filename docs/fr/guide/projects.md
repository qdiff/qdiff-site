# Avant de valider

Un rapide « qu'est-ce que j'ai vraiment changé ? » vaut la peine avant
chaque validation. Ouvrez un dossier de projet dans qDiff et la réponse est
déjà sous vos yeux.

<img src="/screenshots/projects.svg" alt="Une liste de fichiers modifiés à côté d'une comparaison codée par couleur" class="guide-shot" />

## Ouvrir un dossier de projet

Choisissez le dossier d'un projet Git depuis **Fichier → Ouvrir**, ou
déposez-le sur la fenêtre. qDiff réunit les fichiers que vous avez touchés
dans une seule liste.

## Lire la liste, puis les modifications

Chaque fichier est marqué selon ce qui lui est arrivé : nouveau, modifié ou
supprimé. Cliquez sur l'un d'eux et le panneau de droite montre exactement ce
qui a changé à l'intérieur, avec les mêmes couleurs et les mêmes surlignages
au niveau des mots que dans une comparaison de fichiers classique.

Parcourez-les un par un — la liste conserve votre position, si bien que rien
n'est oublié lors d'une longue revue.

## Terminer dans la même fenêtre

Quand tout vous semble correct, validez depuis ici. Vous pouvez aussi mettre à
jour, pousser, annuler ou résoudre un conflit sans quitter la comparaison.
Aucune autre application n'a besoin d'être ouverte, et aucun compte n'est
requis.

::: tip Ce n'est pas un dossier de projet ?
Tout dossier ordinaire s'ouvre quand même comme une comparaison de dossiers
classique — [comparez des dossiers](./folders.md) fonctionne partout.
:::
