# Télécharger et installer

qDiff est une petite application Mac native. Une fois installée, votre
première comparaison ne demande que deux glisser-déposer.

<DownloadButtons />

## Installez en un instant

1. Ouvrez la page du Mac App Store et cliquez sur **Obtenir**, puis sur
   **Installer**.
2. Lancez qDiff depuis le dossier Applications ou depuis Launchpad.
3. Déposez deux fichiers — ou deux dossiers — dans la fenêtre. C'est tout,
   il n'y a rien d'autre à régler.

::: tip Autoriser l'accès à un dossier
La première fois que vous comparez un dossier, macOS peut vous demander si
qDiff peut en consulter le contenu. Choisissez **Autoriser**. Vous gardez la
main : seuls les dossiers que vous choisissez sont lus, et vous pouvez modifier
ce réglage plus tard dans les Réglages.
:::

## Configuration requise {#system-requirements}

| | |
| --- | --- |
| Système | macOS 12 ou version ultérieure |
| Mac | Puce Apple et Intel |
| Compte | Non requis |
| Internet | Non requis pour comparer |
| Langues | anglais, chinois simplifié, chinois traditionnel, japonais, allemand, espagnol et français |
| Apparence | Clair et sombre |

## Gratuit, avec un achat unique facultatif

Toutes les comparaisons, toutes les vues et tous les exports fonctionnent
sans paiement. La version gratuite affiche simplement une mention « sans
licence » dans la barre d'onglets. Un achat unique retire cette marque et
inclut les futures fonctions premium — sans abonnement, sans publicité, sans
compte. Les achats sont liés à votre Apple ID et peuvent être restaurés à
tout moment depuis les Réglages.
